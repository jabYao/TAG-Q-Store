### 1.5 Componentes Clave

#### 1.4.1 Hero Banner
- **Propósito**: Captar atención inmediata y dirigir a colección destacada
- **Elementos**:
  - Imagen de fondo (configurable desde admin)
  - Título principal (H1)
  - Subtítulo descriptivo
  - CTA principal (color dorado #D4AF37)
- **Comportamiento**:
  - Imagen responsive (diferente para mobile/desktop)
  - Lazy loading para imágenes below fold
  - CTA con hover effect (oscurecimiento sutil)

#### 1.4.2 Sección de Beneficios
- **Propósito**: Generar confianza inmediata
- **Elementos**: 4 íconos con texto corto
- **Regla**: Siempre visible, no depende de contenido dinámico

#### 1.4.3 Categorías Destacadas
- **Propósito**: Navegación rápida por categoría
- **Elementos**:
  - Imagen de categoría
  - Nombre de categoría
  - Link "Ver →"
- **Layout**:
  - Desktop: Grid 3 columnas
  - Mobile: Stack vertical

#### 1.4.4 Grid de Productos (Destacados / Nuevos)
- **Propósito**: Mostrar productos con CTA de compra
- **Elementos por tarjeta** (usar `skillsTarjetaUI-frontend`):
  - Imagen del producto
  - Nombre
  - Precio (formato COP)
  - Badge "Envío Gratis" si aplica
  - Botón "Agregar al carrito"
- **Layout**:
  - Desktop: Grid 4 columnas
  - Mobile: Scroll horizontal (snap)
- **Comportamiento**:
  - Hover: sombra sutil + escala 1.02
  - Click en imagen: ir a detalle de producto
  - Click en botón: añadir al carrito (sin recargar)

#### 1.4.5 Banner Promocional
- **Propósito**: Comunicar envío gratis
- **Elementos**:
  - Mensaje destacado
  - CTA "Comprar Ahora"
- **Color**: Fondo azul (#0B2977) con texto blanco

| Elemento | Regla |

### 7.5 Componentes Clave

| Componente | Comportamiento |
|------------|---------------|
| Item Card | Imagen miniatura, nombre (link a detalle), descripción variante, precio unitario, selector cantidad, botón ✕ para eliminar. Desktop: lista vertical. Mobile: cards compactas |
| Selector Cantidad | [−] [+] con input. Actualiza subtotal en tiempo real. Mínimo 1 |
| Cupón | Input + botón "Aplicar". Al aplicar exitosamente, muestra descuento en resumen. Si inválido, mensaje error inline |
| Resumen | Sticky en desktop, flujo normal en mobile. Subtotal, envío, descuento (si aplica), total. CTAs |
| Checkout CTA | Botón "Iniciar Checkout" prominent. Redirige a /checkout/resumen |
| Recomendados | Grid de productos basados en items del carrito. Misma tarjeta que Catálogo |
| Seguir comprando | Link que vuelve al catálogo o última categoría visitada |

| Botones | "Continuar" (siguiente paso), "Confirmar pedido" (último paso), "Volver" (paso anterior). Siempre visibles al final del contenido |

### 2.3 Estados

#### Loading
- Botón INICIAR SESIÓN: text cambia a "Ingresando..." + spinner SVG rotando
- Inputs disabled, opacidad 0.7
- Timeout: 30s → error

#### Error
- Input de contraseña: border-color #DC2626 (red-600)
- Mensaje arriba del botón: "Credenciales inválidas" en bg #FEF2F2, text #DC2626, padding 12px, border-radius 8px

#### Success
- Redirección a home (rol cliente) o admin (rol admin)
- Flash toast: "Sesión iniciada correctamente" → bg #059669, text #FFFFFF, 14px, bottom-right
